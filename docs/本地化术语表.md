> 适用版本：二开基线 `5c9caa7` 之后 · 2026-11-12
> 权威译文：`tools/l10n/zh_full.json`（697 条，按 l10n key 索引）

## 一、两条硬规则

1. **按国人影音圈的习惯用词，不做字面直译。** 面向的是中文 Emby / Jellyfin / NAS / 家庭影院用户，术语要让他们一眼看懂。
2. **服务、协议、技术专名一律保留原文**（用户明确要求）：Emby、Jellyfin、TMDB 等不翻译，也不加中文注释式意译。

品牌 `Zerk Play` → `AusHD Player` 属于品牌替换，不是翻译；上游项目名仅在 README 的 GPL 来源声明中保留。

### 状态徽章（全大写 → 中文短词，10-foot UI 要短）

### 一起看 / 推荐语

## 五、本轮修正的错译

上一版骨架里有几处对不上英文原义，已一并改正：

- `settingsGroupContentLanguages`：原文 `Titles & trailers`，曾误译「内容与语言」→ **片名与预告片**
- `calendarDisc`：原文 `Blu-ray & DVD release`，曾译「光盘发行」→ **蓝光 / DVD 发行**
- `calendarTv`：原文 `TV premiere`，曾译「电视播出」→ **电视首播**
- `trailerLanguageOriginal`：原文 `Original (official trailer)`，曾译「原声」→ **原声（官方预告片）**
- `subtitlePreviewLine1/2`：两句改成连贯对白「天黑前我们得走了。」/「那现在就走吧。」
- `qualityDirect`：`Original / Direct` 由「原画 / 直连」→ **原画 / 直接播放**

## 六、技术处理（保证 `flutter gen-l10n` 必过）

- **占位符**：`{count}` `{date}` `{percent}` `{error}` 等全部原样保留；校验脚本逐 key 比对占位符集合，不一致就报 FAIL。占位符正则只认 ASCII 标识符，避免把中文 ICU 分支（如 `=0{未选择}`）误判成占位符。
- **ICU 复数**：中文无复数变化，但保留与英文相同的 `=0` / `=1` / `other` 分支结构，分支文案按中文习惯写（`1 季` / `共 {count} 季`、`1 部` / `{count} 部`）。校验脚本比对分支标签集合。
- **日期**：`calendarDay` / `calendarMonth` 的 `{date}` 交给 `intl` 按 `zh` 格式化；`details_parts.dart` 的 `formatDate()` 增加中文分支，输出 `2026年11月12日`（原来是 `12 Nov 2026` 式），其它语言不受影响。
- **monthsShort**：改为 `1月 … 12月`，仍是 12 个空格分隔项，`split(' ')` 不会越界。
- **手机扫码配置页**：`setup_page.dart` 整页中文化（标题、区块、标签、占位提示、JS 结果消息），`lang="zh-CN"`、补齐中文字体、默认应用语言改 `zh`；`remote_setup_server.dart` 的 5 条状态消息改为中文。
- **残留品牌**：窗口标题、webhook 请求体、设备标识、日志头、生成的 `mpv.conf` 注释、Janus 客户端名全部改为 AusHD Player，`lib/` 下已无 `Zerk Play`。
